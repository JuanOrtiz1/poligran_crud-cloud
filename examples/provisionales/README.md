# Datos ficticios provisionales

Estos CSV prueban un esquema inventado **solo para las pruebas automatizadas**:
`codigo` (texto obligatorio), `nombre` (texto obligatorio), `cantidad` (entero obligatorio).
No representan tu base existente y no deben importarse en ella.

`valido.csv` contiene tres filas válidas. En `con-errores.csv`, sobre un repositorio vacío,
se crea la primera fila y se omiten las otras tres: ID repetido, tipo inválido y nombre ausente.
Los números de fila incluyen el encabezado (primera fila de datos = 2).
